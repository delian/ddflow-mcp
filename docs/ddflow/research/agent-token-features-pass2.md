## 1. GitHub Copilot (VS Code and Copilot CLI)

Billing context first, because it changes the cost levers. Since 2026-06-01 Copilot is **usage-based**: every model call is converted to **AI Credits**, `prodname_ai_credits_value: '$0.01 USD'` (github/docs `data/variables/product.yml`), from input, cached input, cache write and output tokens at per-model prices. Source: `content/copilot/concepts/billing-and-usage/individuals/billing.md`, `reference/copilot-billing/models-and-pricing.md`, `data/tables/copilot/models-and-pricing.yml`.

### 1.2 Prompt cache (the first pass had U)

- Per-token cache prices exist for every model (`cached_input`, and `cache_write` for Anthropic and GPT-5.6+): cache is billed, so it is real. Source above. V.
- **TTL as stated to users**: `tutorials/optimize-ai-usage.md`: "Caches expire after a period of inactivity (24 hours for OpenAI models and 1 hour for most others)". V (vendor statement; the user cannot set it). Contradicted in nuance by the VS Code blog: OpenAI default "dropped after about 5 to 10 minutes of inactivity (up to an hour in some cases)", extended via `prompt_cache_retention: "24h"` set by the client for supported models. So: **harness-controlled, no user setting**. V.
- Anthropic path: the VS Code harness places "up to four breakpoints": end of tool definitions, end of system prompt, and two rolling message anchors; reported hit rate "around 94%" for agentic workloads (blog 2026-06-17). V (statement), R (the 94% is the vendor's).
- What busts it (vendor list, `optimize-ai-usage.md` section 4): switching models mid-session; returning after the TTL; "Changing the reasoning effort level, context size, or the set of enabled tools and MCP servers during a session". VS Code Cache Explorer (`docs/agents/agent-troubleshooting/cache-explorer.md`, Agent Debug Logs > Summary > Cache Explorer) diffs consecutive requests and shows "the first divergence" and cache-hit percent per turn. V. This is a **query surface**, interactive only.
- Machine-readable cache numbers: SDK event `assistant.usage` (per model call, includes sub-agents; "ephemeral ... not replayed when you resume") and RPC `session.usage.getMetrics` (`totalNanoAiu` / 1e9 = credits). V (`copilot-sdk/features/usage-and-billing.md`). CLI `/usage` shows per-model token totals and credits per model (cli-command-reference `/usage`). V. `-s/--silent` hides usage statistics. V.

### 1.5 Limits, quota, reset (the first pass had U)

- **`--max-ai-credits=CREDITS` and `/limits set max-ai-credits N`**: a soft cap that stops the agent cleanly; minimum 30 credits; "If a response is in progress when the limit is reached, that response completes". Non-interactive: "the run ends when the limit is reached". Public preview. **The two pages disagree on scope**: how-to page: "caps the amount of AI Credits that Copilot can spend in a session"; CLI reference: "soft maximum for AI Credits allowed for each response. The limit resets per user message". Treat the scope as **U** until a fixture shows it; for a one-prompt `-p` run both readings coincide. SDK equivalent `sessionLimits: {maxAiCredits: 30}`. V (existence), U (scope).
- Exit code when the cap stops a `-p` run: not documented (U). Messages for rate limits: not documented (U; `usage-limits.md` lists only advice).
- **Quota query**: (a) `footer.showQuota` and the status bar/status dashboard (interactive); (b) SDK RPC `account.getQuota` returns `quotaSnapshots` keyed `premium_interactions`, `chat`, `completions` with `entitlementRequests` (-1 unlimited) and `resetDate` (ISO 8601); (c) `session.quota.get` / `session.quota.refresh` and event `session.quota_observation` (provider quota observations, `authoritative_budget` vs `advisory_balance`); marked experimental. V (docs), but these are SDK/server RPC, not a CLI flag, and the page notes some quantities are advisory. Monthly reset is `00:00:00 UTC` on the 1st for AI credits. The `statusLine` setting runs a command with session JSON on stdin; the JSON fields are not documented (U).
- Rate-limit fallback: setting `continueOnAutoMode` (default false) "Automatically switch to auto mode when rate-limited ... Does not apply to global rate limits or BYOK providers". V.
- `/chronicle cost-tips` (CLI) and `/chronicle:cost-tips` (VS Code) generate personal cost advice from session history. V. Session history `~/.copilot/` (`session-state`) is local; transcript path passed to hooks as `transcriptPath`. V (hook input).
